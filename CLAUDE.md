# Tanner Golf

## Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS
- Sanity CMS (embedded Studio at `/studio`)
- Hosted on Vercel

## Content rules
- Every piece of visible text must be editable in Sanity — no hardcoded copy in components.
- Every image must be a Sanity image field (with alt text and hotspot), rendered via `next/image`.
- Designs come from Figma; build pages to match the Figma frames.
